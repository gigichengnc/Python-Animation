# Python-Animation

A from-scratch Python pixel-animation project for **一段文字，一段路 / A Small Chapter for the Ride**.

The goal is not to shake or filter an existing GIF. The project will render an original pixel-art train scene as separate animated layers: a stable carriage, moving scenery, parallax depth, lighting changes, reflections, and character micro-animation.

## First milestone — v0.1 Pixel Train Engine

- native low-resolution pixel canvas
- nearest-neighbour upscale only
- fixed pixel-art palette
- layered parallax scenery
- stable train interior
- passenger blink / breathing micro-animation
- window reflections
- deterministic rendering
- GIF and MP4 export
- automated smoke test

Development will happen in small reviewable milestones so the visual engine can later be reused across episodes.
