# v0.3 — 480×270 high-resolution pixel canvas

v0.3 moves the production renderer from 320×180 to **480×270 native pixels**.

At the default 4× nearest-neighbour scale, this exports directly to **1920×1080 Full HD** while retaining hard pixel edges.

## Why 480×270

The earlier 320×180 prototype was useful for engine validation, but it constrained:

- face and hair readability
- clothing and prop shading
- carriage geometry
- window / handle detail
- city window density
- trackside speed cues

480×270 adds 2.25× as many native pixels without abandoning the pixel-art look.

## What was rebuilt

This is not a stretched 320×180 scene.

- larger center-window composition
- rebuilt ceiling, route display, door posts, handles, cushions and flooring
- more detailed original passenger sprite
- more detailed companion sprite
- denser two-layer city generation
- larger mountain shapes
- refined poles, lamps, signals and gantries
- stepped diagonal glass reflections
- Full HD 4× output path

## Rules remain unchanged

- no anti-aliasing
- nearest-neighbour upscaling only
- fixed palette
- one-pixel character micro-motion
- deterministic seeded world generation
- seamless loop phase

## Review gate

The next pass should refine **pixel-art craft**, especially the passenger face/hair silhouette and carriage material shading. Timeline features remain deliberately postponed until the base visual is approved.
