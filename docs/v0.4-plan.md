# v0.4 — 2560×1440 production canvas

v0.4 is an architecture reset, not a simple resize of v0.3.

## Render targets

| Target | Resolution |
|---|---:|
| Native art canvas | 2560×1440 |
| 2× master | 5120×2880 |
| 4K delivery | 3840×2160 |

The compositor always works at native resolution. Export scaling is a separate concern.

## Layer contract

Every visual element enters the frame through a `Layer`.

A layer may come from:

- a cached static RGBA surface
- a PNG asset
- a deterministic phase-driven frame factory

This means we can start with procedural placeholders and progressively replace them with carefully authored pixel-art assets without rewriting animation logic.

## Animation cadence

- render / scenery: 24 fps
- character pose changes: 8 fps
- longer production loop target: 30–60 seconds

Character motion remains intentionally stepped even when the world scrolls more smoothly.

## v0.4 visual gate

Do not add tunnel, station, weather, passing-train, or narration-timeline systems until the 2560×1440 base still feels strong enough to represent the channel by itself.
